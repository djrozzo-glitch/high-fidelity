# High Fidelity Clerk Pack

This pack contains 6 transparent PNG poses for the record-store clerk character, based on the supplied likeness reference.

## Files
- idle.png — relaxed neutral pose
- perfect.png — approving thumbs-up
- groove.png — dancing / In the Groove
- rare.png — excited about rare pressing
- nervous.png — worried about balance
- panic.png — full panic

A helper integration snippet is included in `clerk-integration-snippet.js`.
